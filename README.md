# uninstall-360-suite

一个用于检查和清理 Windows 上 360 系列软件残留的 Skill。包含检查脚本、分步处理说明和常见痕迹参考表。

## 使用前

先读 [SKILL.md](SKILL.md)。在自己的电脑或获得授权的电脑上操作；清理前备份重要数据，确认每个待删除对象的归属。脚本根据一次真机处理经历整理，尚未在各种 Windows 环境中充分验证。

## 文件与运行顺序

| 文件 | 用途 |
|---|---|
| `scripts/01-Scan.bat` | 只读检查；在桌面生成 `360-scan-report.txt` |
| `scripts/04-Repair-Browser.bat` | 预览后可处理带 360 参数的浏览器快捷方式；其他浏览器设置需人工核对 |
| `scripts/02-Stop-360.bat` | 预览并确认后停止匹配的进程和服务 |
| `scripts/03-Clean-Remnants.bat` | 预览并确认后清理固定目录、厂商注册表键和驱动文件；先尝试创建系统还原点 |

建议按 `01 → 04 → 02 → 03` 检查和处理。先看预览，再决定是否执行。启动项、计划任务、右键菜单与浏览器策略只报告，不自动删除。若创建还原点失败，`03` 会停止，不会继续清理。

## 隐私

参考表保留了真机案例的技术过程，但没有姓名、账号、设备序列号或真实内部域名。扫描报告、浏览器快捷方式备份、注册表导出和日志可能包含用户名、文件路径或浏览器配置。这些文件保存在本机，不属于仓库内容；分享报告前请自行检查并脱敏。`.gitignore` 排除了常见生成文件，但仍需在上传前核对 Git 文件清单。

## 范围

这里的清单针对 360 系列软件。匹配到 `360` 字样不等于对象一定属于 360，尤其是计划任务、浏览器策略和其他软件的路径。不要直接套用到其他安全软件。
